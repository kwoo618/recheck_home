## 사진을 어디서 받나

**사진 파일은 저장소에 없다.** `.gitignore` 대상이라 커밋되지 않는다(`/docs/qa/shots/`, `/docs/qa/pdf/`).
받는 방법은 둘 중 하나다.

> 비전공자 팀원에게는 이 문서 말고 **`docs/qa/README-팀원용.md`** 를 주면 된다.
> 같은 내용을 용어 없이 다시 쓴 것이다.

### ① 직접 찍는다 (권장 — 항상 최신)

```bash
npm run qa:seed                                    # QA 매물 5건 시드
npx next build                                     # ★ 3000 포트를 먼저 비울 것
node --env-file=.env.local node_modules/next/dist/bin/next start -p 3000
npm run qa:shoot                                   # 13화면 × 390/768/1440 + PDF 2종
```

**반드시 포트 3000.** 다른 포트면 카카오 JS 키 도메인 제한으로 지도가 폴백 리스트로 찍힌다.
절차 함정(재빌드 순서 등)은 `tests/e2e/README.md`에 정리돼 있다. 약 2분 30초 걸린다.

### ② 찍어둔 것을 받는다

프론트 세션이 2026-08-12에 찍은 세트가 로컬 `docs/qa/shots/`에 있다. 필요하면 요청할 것.

## 3. 남은 일 — 발표 준비만

### 발표 전
- [ ] 발표 논지 정리 (팀에 위임했으나 아래 3개는 강우가 답할 수 있어야 함)
  - "AI 서비스인데 AI가 판단을 안 한다고요?" → R1 + `/admin`의 **규칙 : AI 비율**
  - "직방·다방과 뭐가 다르죠?" → 찾는 게 아니라 이미 찾은 걸 검증
  - "그냥 체크리스트 앱 아닌가요?" → 규칙 기반 항목 선정 + 상태 전이
- [ ] **D4 리허설** — `docs/INFRA.md` §5 체크리스트를 순서대로. 특히:
  - Neon 웜업(발표 직전 1회 접속 — scale-to-zero 콜드 스타트)
  - `/admin`은 **미리 다른 탭에 열어둘 것** (주소창에 토큰이 보인다)
  - 랜딩은 **시크릿 창**으로 확인 (세션 재시작 버튼은 되돌릴 수 없다)
  - **사글세는 시연 중 직접 등록**해서 보여준다 (시드에 없다)
- [ ] 저장소 public 전환 여부 판단
  - 전환 전 `git log --all --pretty=format: --name-only | sort -u | grep -i env` 감사
- [ ] 발표 후 Vercel에서 `ADMIN_TOKEN` 삭제 → `/admin`이 `notFound()`로 막힌다

### 미확인으로 남긴 것 (R8 — 추측 금지) · 실측 보류

- [ ] Gemini 무료 티어 RPM/RPD
- [ ] 카카오 로컬 API(주소→좌표) 일일 한도 — 지도 SDK 30만회와 **별개 쿼터**

## 4. 발표에서 다룰 판단 사항

### ① 작업 기간
git 이력 기준 **2026-08-11 12:21 → 2026-08-12 14:53**, 총 커밋 82개.
계획은 4일이었고 핵심 기능은 하루에 끝났다.
"빨랐다"를 강조할지 "계획 대비 이렇게 진행됐다"로 설명할지는 선택. **커밋 이력 기준으로 말하는 것이 안전하다.**

### ② 화면 수 표기
프론트가 `docs/SCREENS.md`에서 세고 있다. **그 문서를 단일 소스로 쓸 것.**
`docs/PRD.md`에는 화면 수 표기가 없다(§7 와이어프레임은 개수를 주장하지 않는다).

### ③ 지표는 절대값이 아니라 비율로 말한다
`/admin`의 `규칙 : AI`는 **매물 1건당**으로 정규화돼 있다.
절대값(예: 560 : 5)은 시연용 데이터가 늘리는 숫자라 "실제로는 몇 건인가요"에 답하기 곤란하다.
대시보드는 절대값도 **실사용 / 시연용으로 갈라** 함께 보여준다.

## 5. 알려진 한계 (고치지 않기로 한 것)

| 항목 | 이유 |
|---|---|
| 브라우저 뒤로가기로 이탈 시 방문 기록 유실 | App Router에 이동 가로채기 공개 API 없음. `history` 조작은 부작용이 큼 |
| 동시 요청 중복 3건 (등록·질문 토글·항목 추가) | 클라이언트 가드(`useMutations`)로 막음. 서버 차단은 스키마 변경이 필요해 보류 |
| 도보 최소거리 미지원 | 카카오 길찾기는 유료 API. 직선거리 + "직선거리 기준 추정" 병기가 R8의 표현 |
| 면적·관리비 빈 값이 0으로 저장 | nullable 스키마 변경 대신 표시로 우회. 관리비 0은 실제 값일 수 있어 그대로 표시 |
| 홈·비교 화면 `Ctrl+P` 시 화면 그대로 인쇄 | 인쇄 버튼이 없는 화면. MVP 범위 밖 |
| **사글세는 등록·검증까지 지원. 비교 환산은 미지원** | 계약 기간이 제각각이라 환산하려면 재계약 횟수·중개보수를 서비스가 가정해야 하는데, **그건 R8에서 하지 않기로 한 일이다.** 사글세끼리는 월 환산액·처음 드는 돈으로 비교 가능. 남은 항목은 `docs/ROADMAP-V2.md` |
| **`/admin` 인증이 실제 인증이 아님** | **발표용 임시 구현.** `?key=`와 `ADMIN_TOKEN` 문자열 비교가 전부다. URL이 히스토리·로그·Referer에 남는다. **발표 슬라이드에 URL을 넣지 말 것.** 로그인 도입 시 교체 |
| 퍼널의 제외(excluded) 매물은 등록 단계까지만 집계 | 제외 시점의 진행 단계를 기록하지 않는다. 뒤 단계 전환율이 실제보다 낮게 나올 수 있고, 화면에 그렇게 적었다 |
| **세션 재시작은 되돌릴 수 없음** | 쿠키만 바꾸므로 데이터는 DB에 남지만, 이전 세션 값을 어디에도 남기지 않아 다시 접근할 방법이 없다. 화면이 확인 단계를 둔다 |
| 시연용 시드에 사글세 0건 | 팀원 추가분을 받지 않기로 했다. **없는 데이터를 만들지 않는다.** 시연 중 직접 등록해서 보여준다 (팀원 실사용 사글세 1건은 이미 있다) |
| 지역 분포가 읍·면·동까지만 | 길 단위로 내리면 동네 안에서 매물을 특정할 수 있다. 개인정보 제한 취지가 우선 |
| 시드 40건 중 5건 지오코딩 실패 | 전부 `상림3길`. 좌표 null로 저장돼 "위치 미지정"으로 빠지고 검증·비교·인쇄는 정상 동작 (R4) |

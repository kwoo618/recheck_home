## 4. D1 OCR 실측표 (중단 규칙의 근거)

> 프론트 세션 D1 오전 산출물. **채워지기 전에는 촬영본 지원 여부를 아무 문서에도 적지 않는다 (R8).**
> 언어 데이터는 `tessdata_fast/kor` 단독(1.60MB)으로 시작한다. 표준판(14.61MB)을 쓰지 않는다.

| 파일 | 종류 | 텍스트 레이어 | 암호화/권한 | 인식률 (10필드) | bbox | 처리 시간 | 언어데이터 |
|---|---|---|---|---|---|---|---|
| | 등기부 PDF | | | /10 | | | |
| | 등기부 촬영 | — | — | /10 | | | |
| | 계약서 | | | /10 | | | |
| | 광고 캡처 | — | — | /10 | | | |

**분기** (V2-TECH-REVIEW §2-3)
- 텍스트 레이어 **있음** → 등기부는 OCR 없이. Tesseract는 광고 캡처·촬영본 전용으로 축소
- 없음 + 인식률 양호 → 계획대로, 페이지 선별로 시간 관리
- 없음 + 인식률 불량 → 기기 OCR은 광고 캡처 전용, 등기부·계약서는 서버 경로
- 촬영본 전부 불량 → **PDF 전용으로 좁힌다** (계획 변경이 아니라 계획 실행)

## 7. 미확인 (R8 — 추측 금지)

**v1에서 물려받은 것** — 전부 미확인으로 두고 진행한다. 한도에 닿으면 조용히 폴백으로 내려가고, 출처 배지가 `AI` → `규칙 기반`으로 바뀌는 것이 신호다.

- Gemini 무료 티어 RPM/RPD
- 카카오 로컬 API 일일 한도 (지도 SDK 30만회와 별개 쿼터)
- 우편번호 서비스 사용 조건·한도
- 카카오 상업적 이용 조건

**v2에서 새로 생긴 것**

- **Gemini 이미지 입력 쿼터** — 서버 OCR 폴백이 쓴다. 텍스트보다 빨리 태울 수 있다. 시연 직전에 반복 호출하지 않는다
- 등기부 PDF 텍스트 레이어·암호화 여부 (D1)
- 촬영본 OCR 인식률·처리 시간 (D1)
- Vercel 함수 `maxDuration`과 Gemini 이미지 응답 시간 (D2)
- iOS Safari PWA 저장소 회수 동작 (D4)

# fixtures/ — 더미 데이터

> JSON에는 주석 문법이 없어 출처를 이 파일에 남긴다.

## properties.json

**카카오 로컬 API 조회, 2026-08-11. 실존 주소이나 매물 정보는 더미.**

주소와 좌표만 실제 값이고, 나머지(가격·면적·연식·난방·층수·상태·진행률)는 화면 확인용으로 지어낸 값이다.
실제 매물이 아니며 어떤 임대 조건도 나타내지 않는다.

| 매물 | 주소 (실존) | 좌표 | `distanceFromSchool` |
|---|---|---|---|
| 대구대 원룸 A | 경상북도 경산시 진량읍 대구대로 238 | 조회값 | 582m |
| 진량 투룸 B | 경상북도 경산시 진량읍 진량내리길 30 | 조회값 | 721m |
| 하양 원룸 C | 경상북도 경산시 하양읍 하양로 88 | **null** | **null** |

- 좌표는 카카오 주소 검색 API(`/v2/local/search/address.json`) 응답의 `y`(위도)·`x`(경도)를 그대로 넣었다.
- `distanceFromSchool`은 `lib/geo.ts`의 `distanceFromSchool()`로 계산한 값이다.
  **기준점은 `SCHOOL_ORIGIN`(대구대 경산캠퍼스 대표 좌표)이며 정문이 아니다.**
- **C는 좌표가 null이다.** 주소는 실존하지만 "좌표 획득에 실패한 매물"을 재현하기 위해 의도적으로 비웠다.
  홈 화면에서 "위치 미지정" 그룹으로 빠지고, 지도에 핀이 찍히지 않는 경로를 확인할 수 있다. (R4)
- `addressDetail`은 전부 빈 문자열이다. 동/호수를 더미로라도 넣지 않는다. (R7)

### 주의 — `SCHOOL_ORIGIN`을 바꾸면 이 값도 다시 계산해야 한다

`distanceFromSchool`은 기준점에 의존하는 **캐시된 값**이다. `lib/geo.ts`의 `SCHOOL_ORIGIN`이 바뀌면
여기 적힌 582·721도 함께 틀어진다. 실제로 2026-08-11에 기준점을 교체하면서 한 번 어긋난 적이 있다
(자세한 경위는 [docs/INFRA.md](../docs/INFRA.md) 트러블슈팅 표 참조).

검산 방법:

```ts
import { distanceFromSchool } from '@/lib/geo';
distanceFromSchool(35.8968087410059, 128.848993123294); // → 582
distanceFromSchool(35.904840284559,  128.841628269988); // → 721
```

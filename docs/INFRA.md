| **R1이 실제로 작동한다** | `/api/ai/parse`에 `"이 매물 진짜 좋아요 강력 추천합니다 안전합니다"` | `{"ok":false,"reason":"인식된 항목이 없습니다."}` — **한 필드도 통과하지 못함** | 판정성 표현은 프롬프트 가드레일과 `containsBanned()` 필터를 못 넘는다. AI가 판정을 못 하게 막았다는 주장을 증거로 보여줄 수 있다 (2026-08-11 관측) |
| **AI 결과를 사람이 2차 확인한다** | 붙여넣기 파싱에서 `"2008년 준공"` → `age: 16` (실제 18) | 정보 확인 화면(PRD §5.2)에서 사용자가 수정 | "자동 취득 정보는 틀릴 수 있다"가 추상적 우려가 아니라 실제로 발생한다. 전 필드 편집 가능한 확인 화면을 반드시 경유하게 만든 이유 (2026-08-11 관측) |
| **AI가 죽어도 흐름이 안 끊긴다** | `/api/ai/questions` (키 없이) | `{"ok":false,"questions":[3건],"source":"template"}` | 질문 은행 폴백. 출처 배지만 AI → 규칙 기반으로 바뀐다 (R4) |
| **지도가 죽어도 검증은 된다** | 카카오 SDK 로딩 차단 | 리스트 뷰로 대체 + 하단 문구 유지 | 외부 의존성 폴백 (R4) |

## 4. 트러블슈팅 기록

> 같은 문제로 두 번 막히지 않도록 기록.

| 증상 | 원인 | 해결 |
|---|---|---|
| (대비) `drizzle-kit push`가 DDL에서 실패 | pooled 연결에서 일부 DDL 제약 | Connect 모달에서 pooling 끈 unpooled 문자열로 마이그레이션만 실행. `.env.example`에 `DATABASE_URL_UNPOOLED` 추가 시 계약 변경이므로 결정 로그에 기록 |

| **정문 주소(`대구대로 201`)를 지오코딩했더니 "정문에서 3.4km"로 표시됨** | `lib/geo.ts`의 `SCHOOL_ORIGIN` 경도가 실제 캠퍼스보다 약 0.042도(≈3.9km) 어긋난 **추정값**이었음. 확정 파일이라 검증 없이 신뢰하고 있었다 | 카카오 로컬 API 조회 좌표(`35.90203906952692`, `128.84884246650373`)로 교체하고, 기준을 **캠퍼스 중심**으로 문서·코드에 명시. `tests/geo.test.ts`에 좌표 고정 + "캠퍼스 부지 내 지점은 기준점에서 1km 이내" 회귀 테스트 추가 |
